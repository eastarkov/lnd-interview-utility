# LND Interview Utility

Приложение для расшифровки интервью на Mac. Найденные по словам фрагменты можно собрать на таймлайне и открыть в After Effects со ссылками на оригиналы.

## Установка на Mac

1. Скачайте ZIP для Mac из раздела **Releases** и распакуйте его.
2. Откройте `Start.command`. Если macOS блокирует запуск, откройте Terminal в папке приложения и выполните `bash Start.command`.

Если подходящего Python нет, скрипт скачает Python 3.12 в папку приложения без пароля администратора. При первом запуске понадобится интернет для загрузки Python и зависимостей. После установки приложение откроется в браузере.

Если у вас уже есть библиотека, остановите прежний сервер через Ctrl+C и обновите файлы в существующей папке приложения. Расшифровки и монтаж хранятся в скрытой папке `.data`.

## Ручной монтаж

Откройте «Ручной монтаж» и выберите запись из видеотеки или добавьте видео с Mac. Запись откроется целиком. Во время просмотра нажмите «Начало здесь» и «Конец здесь», чтобы поставить границы по текущему кадру. Границы также можно подвинуть жёлтыми ручками или ввести вручную.

Нажмите «Добавить в монтаж». Отрезок появится на общем таймлайне внизу, а вы сможете продолжить просмотр и выбрать следующий. Видео, добавленные из этого раздела, доступны сразу. Если позже понадобится поиск по словам, запустите расшифровку в видеотеке через «Подробнее → Управление записью».

## От поиска до композиции

1. В «Добавить видео» нажмите «Выбрать видео на Mac» и укажите оригиналы. Файлы остаются на диске по прежним путям. Если системное окно не открылось, используйте «Указать пути вручную».
2. Для файлов из старой библиотеки откройте «Управление записью → Привязать оригинал». Можно также добавить эти же файлы через «Добавить видео»: приложение сопоставит их по содержимому и сохранит готовые расшифровки, имена и границы. Если переместили оригинал, привяжите его по новому пути.
3. Найдите фразы, отметьте нужные фрагменты и соберите их в закреплённом таймлайне. Нажмите «Экспорт в After Effects». Приложение сохранит `VideoWords.jsx`; его расположение можно посмотреть в «Как открыть в AE».
4. В After Effects откройте пустой или существующий проект и выберите [File → Scripts → Run Script File…](https://helpx.adobe.com/after-effects/desktop/automate-in-after-effects/automate-animation/scripts.html). Запустите `VideoWords.jsx` и сохраните проект как `.aep`.

Каждый отрывок станет слоем с именем говорящего, исходной видеодорожкой и её звуком. В AE можно снова раздвинуть границы слоя в пределах полного исходника. Один файл используется повторно, даже если в монтаже из него несколько отрывков. Начало и конец слоёв привязываются к кадрам композиции, чтобы между фрагментами не было зазоров. При первом запуске размер и частота кадров берутся из первого исходника; новые слои иных размеров вписываются в кадр. Цвет HDR/SDR обрабатывается в AE с настройками проекта.

## Как обновлять композицию

После изменений нажмите в приложении «Обновить файл для AE». В том же проекте AE снова запустите `VideoWords.jsx`: можно выбрать его через **File → Scripts → Recent Script Files**. Сохраняется тот же путь; скрипт обновляет прежнюю композицию, добавляет новые фрагменты и убирает снятые. Эффекты, маски, трансформации и имена на оставшихся слоях сохраняются; слои, добавленные вручную, остаются в композиции. Монтажный порядок, границы и скорость импортированного слоя при изменении его тайминга берутся из VideoWords. Если вы уже настроили собственный ремап времени, работайте с копией композиции. Если у вас несколько копий с одинаковой меткой, сначала откройте в AE нужную.

Изменения из After Effects обратно в VideoWords не передаются. Скрипт не сохраняет проект автоматически; обновление можно отменить через Edit → Undo. Не удаляйте метки VideoWords в комментариях композиции и её монтажных слоёв: они нужны, чтобы следующий запуск нашёл именно эти объекты. Для исходников, которые AE не поддерживает, скрипт покажет имя файла.

## Видеотека и поиск

На вкладке «Видеотека» видны все добавленные файлы, кадры и статусы обработки. Пока готовятся расшифровка и пересказ, можно заполнять поле «Кто говорит?». Имя, краткое содержание и расшифровка сохраняются между запусками. В меню «Подробнее» можно открыть полный текст, удалить его или перегенерировать. Язык, тема и модель для новых записей находятся в «Настройках». Модели скачиваются при первом использовании. Видео и текст обрабатываются локально.

Подготовка звука и модели показывается отдельными этапами. Процент появляется во время распознавания и доходит до 100% после сохранения текста. По умолчанию используется Whisper Large V3 Turbo. При первом запуске этой модели скачивается около 1,6 ГБ. Для более быстрой обработки в «Настройках» можно выбрать Whisper Small. Кнопка «Расшифровать точнее» позволяет обработать готовую запись заново.

На вкладке «Поиск» учитываются словоформы и основа слова. «Классно» находит «класс» и «классный». Варианты написания можно указать через запятую, например «редизайн, redesign». Можно совместить имя и слово, например «дамир редизайн». Частые слова исключают предлоги и другие служебные слова. Чтобы фрагмент появился на общем таймлайне, нажмите «Добавить в монтаж».

## Предпросмотр и границы

Панель закреплена внизу. Нажмите на фрагмент, чтобы его посмотреть; перетащите за карточку, чтобы изменить порядок. Жёлтые края двигают начало и конец, крестик снимает отметку. Общая шкала перемещает позицию по монтажу. В редакторе исходного видео можно ввести время в формате ММ:СС.ммм и посмотреть весь файл. Для клавиатуры: Alt + стрелки на карточке меняют порядок, Delete убирает фрагмент; стрелки на жёлтом крае сдвигают границу на 0,1 с, Shift + стрелки — на 1 с.

Превью читает оригиналы напрямую. Если браузер не воспроизводит кодек, границы по таймкодам и экспорт остаются доступны. В Safari на Mac может поддерживаться больше форматов, чем в текущем браузере. Для распознавания сохраняется рабочая звуковая дорожка WAV.

## Хранение

Библиотека: `.data/library`; имена: `.data/people.json`; монтаж: `.data/montage.json`; границы и отметки: `.data/clip-edits.json`; тема: `.data/settings.json`. Для связи с проектом AE сохраняйте `.data/after-effects-id` и используйте скрипт по пути `.data/After Effects/VideoWords.jsx`. Модели и пользовательские файлы не включены в архив приложения. Сервер и предпросмотр работают только на 127.0.0.1.
